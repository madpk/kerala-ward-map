# Kerala Ward Map
<img width="1774" height="887" alt="image" src="https://github.com/user-attachments/assets/d909937c-6552-44ae-b585-5a35de8b2179" />

GeoJSON datasets containing local-body and ward boundaries for all 14 districts of Kerala.

## Download

Download the complete datasets from Google Drive:

**[Download Kerala boundary datasets](https://drive.google.com/drive/folders/1fqFf90Slut6qotQEctbJBcVhabVqLdSF?usp=sharing)**

Compressed copies are also available in this GitHub repository.

## Datasets

| Dataset | Contents | Features |
|---|---|---:|
| Kerala local-body boundaries | Local-body boundary GeoJSON | 1,035 |
| Kerala ward boundaries | Ward boundary GeoJSON | 21,000 |

All geometries are stored as GeoJSON `MultiPolygon` features.

## Uses

- GIS applications
- Interactive web maps
- Spatial analysis
- Electoral and administrative research
- Data visualisation

The files can be opened using QGIS, ArcGIS, MapLibre, Leaflet, OpenLayers, GeoPandas and other GIS tools.

## Data source

Boundary data was obtained from the [K-SMART Ward Map](https://wardmap.ksmart.live/).
