# Kerala Ward Map

GeoJSON datasets containing local-body and ward boundaries for all 14 districts of Kerala.

## Datasets

| File | Contents | Features |
|---|---|---:|
| `Kerala_localbody_boundaries.zip` | Local-body boundary GeoJSON | 1,035 |
| `Kerala_ward_boundaries.zip` | Ward boundary GeoJSON | 21,000 |

All geometries are stored as GeoJSON `MultiPolygon` features.

## Uses

These datasets can be used for:

- GIS applications
- Interactive web maps
- Spatial analysis
- Electoral and administrative research
- Data visualisation

The GeoJSON files can be opened using QGIS, ArcGIS, MapLibre, Leaflet, OpenLayers, GeoPandas and other GIS tools.

## Data source

The boundary data was obtained from the [K-SMART Ward Map](https://wardmap.ksmart.live/).
